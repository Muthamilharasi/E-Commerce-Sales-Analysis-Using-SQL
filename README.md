# 🛒 E-Commerce Sales Analysis — SQL Project

## Business Problem
An e-commerce company needed visibility into revenue trends,
product performance, customer behavior, and profit margins
across cities and categories.

## Approach
- Designed a 4-table relational database (customers, products,
  orders, order_items)
- Wrote 18 SQL queries from basic to advanced (Window Functions,
  CTEs, Stored Procedures)
- Built reusable Views and automated monthly report procedure

## Key Insights
1. Electronics drives 68% of total revenue
2. Tamil Nadu is the top state by order volume
3. UPI is the most preferred payment mode (42%)
4. Champions segment customers spend 4× more than At Risk

## SQL Concepts Used
SELECT · WHERE · GROUP BY · ORDER BY · HAVING
JOINS (INNER, LEFT) · Subqueries · CTEs (WITH clause)
Window Functions (RANK, ROW_NUMBER, LAG, NTILE, SUM OVER)
Views · Stored Procedures · Indexes

## Tools
MySQL 8.0 · MySQL Workbench
